# 大运流年命理规则 Skill
## 描述
本Skill提供中国传统命理文化中「大运流年」的完整核心规则、推算方法、分类定义、断盘逻辑与实战使用规范，明确大运与流年的核心作用关系、优先级排序、吉凶判断标准与应期定位规则，是八字命理分析、人生运势趋势推断、人事吉凶预判的核心基础规则，可直接用于八字排盘、命理实战、易学研究等相关场景。

## 适用场景
1. 八字命理排盘与大运流年干支自动推算
2. 人生大运阶段吉凶基调判断与十年运势趋势推断
3. 流年每年具体吉凶事件的应期定位与细节预判
4. 传统易学与命理文化的教学、研究与资料整理
5. 命理类应用/工具的核心推算规则与数据支撑
6. 人生重大决策、事业规划、婚恋择吉、健康趋避的规则参考

## 核心基础逻辑
大运是命主一生的人生阶段划分，主宰十年的整体运势基调，是「舞台」；流年是每一年的具体运势变化，负责引动大运与原局的作用关系，是「演员」。**大运决定吉凶的大方向，流年决定吉凶事件的具体发生时间**，二者必须结合判断，不可拆分。

## 一、大运推算核心规则
### 1. 顺逆排定规则
| 排盘类型 | 适用人群 | 核心规则 |
|----------|----------|----------|
| 顺行 | 阳男、阴女 | 年干为阳（甲、丙、戊、庚、壬）的男命，年干为阴（乙、丁、己、辛、癸）的女命，大运干支按六十甲子顺序正向排列 |
| 逆行 | 阴男、阳女 | 年干为阴（乙、丁、己、辛、癸）的男命，年干为阳（甲、丙、戊、庚、壬）的女命，大运干支按六十甲子顺序反向排列 |

### 2. 起运岁数计算规则
起运岁数决定命主从几岁开始走第一步大运，计算必须精确到二十四节气中的「节」（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒），而非农历初一或公历生日。
1. **基准点确定**：
   - 顺排：从出生日顺数到下一个节的日期
   - 逆排：从出生日逆数到上一个节的日期
2. **时间换算公式**：
   - 3天 = 1岁
   - 1天 = 4个月
   - 1个时辰 = 10天
3. **计算逻辑**：根据出生日与对应节的时间差，按换算公式折算为起运岁数，精确到小数点后两位，对应具体的起运年月。

### 3. 大运干支排盘规则
以命主八字的**月柱**为基准点，在六十甲子表中进行循环排列：
- 顺排：月柱 → 下一组干支 → 再下一组干支，依次排列，每柱干支对应10年运势
- 逆排：月柱 → 上一组干支 → 再上一组干支，依次排列，每柱干支对应10年运势

## 二、大运核心分类与定义
根据大运干支与原局喜用神、地支根基的匹配关系，大运分为三大核心类型，吉凶属性与影响力完全不同：
| 大运类型 | 核心定义 | 吉凶属性 | 影响力说明 |
|----------|----------|----------|------------|
| 实根大运 | 大运地支是原局喜用神的禄、旺、库位，天干透出喜用神 | 上上吉 | 真好运，能量极强，是人生高光阶段，命主可得贵人助力、事业财运稳步提升，诸事顺遂 |
| 虚浮大运 | 大运天干透出喜用神，但地支无根、无强根支撑 | 中平偏吉 | 假好运，看着热闹，实则无力，表面机会多，实则难以把握，易有虚名无实利，做事易半途而废 |
| 交战大运 | 大运地支冲克原局的实根（尤其是日支、月支），天干为忌神 | 大凶 | 凶运，必有剧烈动荡，命主易有事业破败、财运破损、健康问题、是非纠纷、婚姻变动等负面事件 |

## 三、大运断盘核心四步法
### 第一步：定基调——喜忌定性，确定十年核心运势
根据大运干支与原局喜忌的匹配关系，分为四大核心基调，直接决定十年运势的整体走向：
| 大运喜忌组合 | 命名 | 核心状态与运势说明 |
|--------------|------|--------------------|
| 天干为喜，地支为忌 | 盖头（头重脚轻） | 表面看起来很好，有机会有贵人，但实际根基不稳，内在压力巨大，易有表面风光、实则吃亏的情况，做事易先成后败 |
| 天干为忌，地支为喜 | 截脚（底座好，上面烂） | 表面看着倒霉、压抑、阻碍多，但实际内在有根基、有支撑，默默做事可成，易有先难后易、苦尽甘来的情况，适合深耕实干 |
| 天干地支皆为喜 | 顺风顺水 | 人生高光时刻，不用看力量对比，这十年整体运势顺遂，事业、财运、感情均有正向发展，可大胆放手去干 |
| 天干地支皆为忌 | 雪上加霜 | 人生低谷时刻，不用看力量对比，这十年整体运势低迷，诸事不顺，易有接连不断的负面事件，需苟住别动，保守行事，减少风险 |

> 特殊情况：反吟/伏吟，即大运天干地支与原局干支相冲（反吟）或完全相同（伏吟），无论喜忌，均主剧烈动荡，运势起伏极大，易有重大人事变动。

### 第二步：查交战——刑冲合害，定位运势核心触发点
重点查看大运地支与原局地支的刑冲合害关系，确定运势的核心作用节点：
1. 冲：大运冲日支（夫妻宫/身体根基）、冲月支（事业环境/家庭）、冲时支（子女/晚年），主对应维度的剧烈变动、冲突、破败
2. 合：大运合原局地支，主对应维度的绑定、牵绊、合作、机遇，合化成功则彻底改变原局五行结构，合绊则主暂时受限
3. 刑：大运刑原局地支，主对应维度的是非纠纷、反复折磨、健康问题、人事拉扯
4. 害：大运害原局地支，主对应维度的暗中小人、无形伤害、慢性损耗、关系破裂

### 第三步：断吉凶——五行生克，判断运势最终吉凶
1. 生助喜用神：大运生扶原局的喜用神（如原局喜木，大运走水木、木火），为吉，命主可得助力、运势提升
2. 克制忌神：大运克制原局的忌神（如原局忌土，大运走木运），为吉，命主可化解阻碍、摆脱困境
3. 生助忌神：大运生扶原局的忌神，为凶，命主负面运势加重，阻碍增多
4. 克制喜用神：大运克制原局的喜用神，为凶，命主贵人助力受损，好运被破坏

### 第四步：定应期——流年引动，确定事件发生具体年份
大运是运势的「舞台」，流年是引动事件的「演员」，吉凶事件的具体发生时间由流年决定：
1. 大运吉 + 流年吉 = 大吉：对应年份易有升职加薪、结婚生子、创业成功、财运大进等喜事
2. 大运吉 + 流年凶 = 平吉：对应年份整体运势仍向好，但易有局部阻碍、小的波折，不影响整体趋势
3. 大运凶 + 流年吉 = 平凶：对应年份整体运势仍低迷，但可有局部转机、短暂利好，难以改变整体颓势
4. 大运凶 + 流年凶 = 大凶：对应年份易有重大灾祸、事业破败、重病重伤、破财破产等严重负面事件

## 四、流年推算核心规则
### 1. 流年干支定法
流年干支按六十甲子顺序循环，每年一换，**不分男女、不分顺逆**，固定以立春为分界点：立春前为上一年流年，立春后为当年流年，与农历新年、公历生日无关。

### 2. 流年实战核心用法：引动原局
流年的核心作用是「引动」，触发原局与大运的作用关系，核心引动逻辑：
1. 流年地支冲、合、刑原局的日支（夫妻宫）：主当年感情、婚姻、配偶、自身健康相关的事件发生
2. 流年地支冲、合、刑原局的月支（事业宫）：主当年事业、工作、学业、家庭、长辈相关的事件发生
3. 流年地支冲、合、刑原局的年支（祖上宫）：主当年长辈、祖上、不动产、童年相关的事件发生
4. 流年地支冲、合、刑原局的时支（子女宫）：主当年子女、晚辈、投资、晚年健康相关的事件发生
5. 流年天干透出原局的十神：主当年对应十神代表的人事类象凸显，如透出正财主当年财运、配偶相关事项，透出伤官主当年思想、表达、子女相关事项

## 使用说明
1. 大运流年的判断必须严格遵循「大运定基调，流年定应期」的核心逻辑，不可脱离大运单独看流年，也不可脱离流年单独看大运。
2. 大运顺逆排的规则必须严格区分，阳男阴女顺行、阴男阳女逆行是固定规则，不可混淆，否则整个大运排盘完全错误。
3. 起运计算必须以「节」为基准，而非农历初一或公历生日，这是命理排盘的核心细节，直接影响起运岁数的准确性。
4. 大运的喜忌定性是断盘的核心前提，必须先准确判断原局的喜用神，再结合大运干支的匹配关系确定运势基调，不可本末倒置。
5. 流年引动的判断，必须结合大运的整体基调，凶运中的吉流年仅为短暂转机，吉运中的凶流年仅为局部波折，不可单以流年定终身吉凶。
6. 反吟、伏吟的大运流年，无论喜忌均主动荡，需重点关注对应维度的人事变动，提前做好趋避准备。
