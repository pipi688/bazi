# 地支藏干 Skill
## 描述
本Skill提供中国传统命理文化中「地支藏干」的完整规则定义与标准化对应表，明确十二地支各自包含的本气、中气、余气（墓库）天干，以及对应的五行分类、地支分类规则，可用于命理分析、八字排盘等相关场景。

## 适用场景
1. 八字命理排盘与深度分析
2. 地支五行属性与藏干内容快速查询
3. 传统易学文化相关的教学、研究与资料整理
4. 命理类应用/工具的基础核心数据支撑
5. 八字五行强弱计算、十神配置的基础规则参考

## 核心分类规则
十二地支按能量特性与功能定位分为三大类，藏干匹配规则各有明确界定：
1. **四长生地：寅、巳、申、亥**
   - 本气：与地支自身五行完全一致的阳干
   - 中气：对应下一个季节的五行阳干
   - 余气：除亥水外，其余三个长生地支的余气均为戊土
2. **四帝旺地：子、午、卯、酉**
   - 本气：与地支自身五行完全一致的纯阴干
   - 特殊规则：除午火外，其余三个帝旺地支仅藏本气一个天干，无中气与余气
3. **四墓库：辰、未、戌、丑**
   - 本气：与地支阴阳五行属性完全一致的天干
   - 中气：与所属季节匹配的五行阴干
   - 余气：对应上一个季节的五行阴干

## 使用说明
1. 本气为地支的核心五行属性，是该地支最主要的能量来源，决定地支的核心五行定位
2. 中气为地支的辅助五行属性，能量强度仅次于本气，是地支的次要能量来源
3. 余气（墓库）为地支的杂气，仅墓库地支有完整的余气定义，能量强度最弱
4. 四帝旺地中，仅午火同时藏有本气丁火与中气己土，其余子、卯、酉三地支仅藏本气，无其他藏干
5. 四长生地中，仅亥水无余气，其余寅、巳、申三地支均同时具备本、中、余三气
6. 墓库地支的藏干同时覆盖了自身季节、上一季节、下一季节的五行属性，是五行能量的收纳与转换节点
