# 十神命理规则 Skill
## 描述
本Skill提供中国传统命理文化中「十神」的完整核心定义、判定规则、分类逻辑与使用规范，明确以八字日干（命主自身）为中心，根据干支与日干的生克关系、阴阳匹配度划分的十类神煞体系，是八字格局分析、人事吉凶推断、命理细节解读的核心基础规则，可直接用于八字排盘、命理分析、易学研究等相关场景。

## 适用场景
1. 八字命理排盘与十神配置自动匹配
2. 八字格局判断与核心人事特征推断
3. 传统易学与命理文化的教学、研究与资料整理
4. 命理类应用/工具的核心规则与数据支撑
5. 八字五行强弱计算、大运流年吉凶判断的基础规则参考
6. 命主性格、事业、财运、感情等维度的细节解读

## 核心判定逻辑
十神的核心判定完全以**日干（命主自身，简称「我」）**为中心，基于两大核心维度划分：
1. 干支与日干的**生克关系**：生我、我生、克我、我克、同我五大核心关系
2. 干支与日干的**阴阳匹配度**：同阴阳、不同阴阳两大匹配规则
两大维度组合后，形成完整的十神体系，每一个十神都对应唯一的生克+阴阳组合规则。

## 十神核心分类与属性特征
### 按六亲关系分类
1. **比劫类（同我）**：比肩、劫财，代表命主自身、同辈、朋友、竞争关系
2. **食伤类（我生）**：食神、伤官，代表命主的思想、才华、子女、表达输出
3. **财星类（我克）**：正财、偏财，代表命主的财富、物质、配偶、经营所得
4. **官杀类（克我）**：正官、七杀，代表命主的事业、官职、压力、约束、贵人/小人
5. **印星类（生我）**：正印、偏印，代表命主的学业、长辈、贵人、福气、内在支撑

### 按吉凶属性分类
1. **吉性十神**：正印、正官、正财、食神、比肩，多代表稳定、正向的人事与运势
2. **凶性十神**：偏印、七杀、偏财、伤官、劫财，多代表变动、负向的人事与运势
3. 注：十神的吉凶属性并非绝对，需结合八字整体格局、五行旺衰、组合关系综合判断

## 使用说明
1. 十神判定的核心基准为**日干**，所有干支的十神属性都必须以日干为中心进行推导，不可随意更换基准
2. 阴阳匹配是十神划分的必要条件，同一生克关系下，阴阳不同则十神完全不同，不可混淆
3. 十神的核心影响力由五行旺衰决定，当令、得地、得生的十神影响力更强，反之则影响力减弱
4. 大运、流年的十神属性需结合命局原局的十神配置，判断作用关系与吉凶变化
5. 十神的组合规则优先于单个十神的属性，例如「伤官见官」为凶性组合，需优先判断组合影响
6. 不同十神对应不同的人事类象，可用于命主的性格、事业、财运、感情、健康等维度的细节推断，是命理分析的核心抓手
