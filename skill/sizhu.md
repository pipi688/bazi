# 四柱排盘核心规则 Skill
## 描述
本Skill提供中国传统命理文化中「四柱八字」的完整排盘核心规则、算法逻辑、校准标准与实战规范，明确年柱、月柱、日柱、时柱四大柱的排定规则、分界标准、推算方法，是八字命理分析、大运流年推算、格局判断的核心基础，可直接用于八字排盘工具开发、命理实战、易学研究等相关场景。

## 适用场景
1. 八字命理排盘系统的核心算法开发与规则落地
2. 人工八字排盘的精准推算与结果校验
3. 传统易学与命理文化的教学、研究与资料整理

5. 八字格局分析、五行旺衰判断、大运流年推算的基础前提

## 核心基础逻辑
四柱八字是命理分析的核心载体，由年柱、月柱、日柱、时柱四大柱组成，每柱由1个天干+1个地支构成，共八个字，因此也称「八字」。四柱排盘的核心是**以命主出生的真太阳时为基准，严格遵循节气、时辰分界规则，精准推算每一柱的干支**，排盘的准确性直接决定后续所有命理分析的结果。

---

## 一、时间校准（定盘之基）
时间校准是四柱排盘的前置核心步骤，所有干支推算都必须基于校准后的真太阳时，分为真太阳时换算、日界确定两大核心环节。
### 1. 真太阳时换算
- 核心公式：真太阳时 = 北京时间 + 经度差修正 + 均时差修正
- 核心规则：将北京时间（钟表时间）根据出生地经度、均时差（地球公转轨道与自转轴倾角导致的太阳时差异，年最大差值可达±15分钟）换算为真太阳时，以当地太阳位于正南为午时的标准时间，是时辰判断的唯一核心基准。

### 2. 日界确定
- 核心规则：八字以子时（23:00-01:00）为日分界，23:00后即属次日。
- 关键要求：若真太阳时在23:00之后，日柱、时柱必须按第二天计算，不可按当天公历/农历日期推算。

---

## 二、年柱排盘规则
年柱是四柱的根基，代表命主的祖上、早年运势，核心分界点为立春，而非春节（正月初一）。
### 排盘逻辑
1. 基准：以出生当年的立春精确时刻为分界点
2. 核心规则：
   - 出生时间在当年立春之后，年柱为当年干支
   - 出生时间在当年立春之前，年柱为上一年干支
3. 示例：2000年立春时刻为2月4日20:32，2月4日22:00出生者，年柱为庚辰（2000年）；2月4日18:00出生者，年柱为己卯（1999年）。

---

## 三、月柱排盘规则
月柱是定月令旺衰的核心，直接决定命主五行「实根」的强弱，月支只认节气中的「节」，不认农历初一。
### 1. 定月支（月令）
- 核心规则：根据出生时间所在的「节」（节气中的节，非中气）确定月支，交节前为上月，交节后为当月。
- 月支-节气对应表：
| 月支 | 对应节气范围（约） |
|------|--------------------|
| 寅   | 立春-惊蛰前        |
| 卯   | 惊蛰-清明前        |
| 辰   | 清明-立夏前        |
| 巳   | 立夏-芒种前        |
| 午   | 芒种-小暑前        |
| 未   | 小暑-立秋前        |
| 申   | 立秋-白露前        |
| 酉   | 白露-寒露前        |
| 戌   | 寒露-立冬前        |
| 亥   | 立冬-大雪前        |
| 子   | 大雪-小寒前        |
| 丑   | 小寒-立春前        |

### 2. 定月干（五虎遁）
- 核心规则：根据年干，通过五虎遁口诀推算月干，以寅月（正月）为基准，顺推其余月份。
- 五虎遁口诀：甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬位顺行流，若问戊癸何方发，甲寅之上好追求。
- 逻辑说明：年干为甲或己，正月（寅月）月干为丙；年干为乙或庚，正月月干为戊，以此按六十甲子顺序顺推其余月份的月干。

## 四、日柱排盘规则
日柱代表命主自身，是「实根」的核心载体，是四柱排盘的核心基准之一。
1. 排盘规则：日柱无通用推算口诀，必须依赖精确计算或查询《1900-2100年日柱干支对照表》。
2. 关键注意事项：日柱分界为子时（23:00），真太阳时23:00后出生的，日柱必须按次日计算，不可按当天日期推算。

---

## 五、时柱排盘规则
时柱代表命主的晚年、子女、事业归宿，由时支+时干组成，时支固定，时干由日干决定。
### 1. 定时支
- 核心规则：根据真太阳时，按十二时辰对应范围确定时支。
- 十二时辰对应表：
| 时辰 | 时间范围       | 时辰 | 时间范围       |
|------|----------------|------|----------------|
| 子   | 23:00-01:00    | 午   | 11:00-13:00    |
| 丑   | 01:00-03:00    | 未   | 13:00-15:00    |
| 寅   | 03:00-05:00    | 申   | 15:00-17:00    |
| 卯   | 05:00-07:00    | 酉   | 17:00-19:00    |
| 辰   | 07:00-09:00    | 戌   | 19:00-21:00    |
| 巳   | 09:00-11:00    | 亥   | 21:00-23:00    |

### 2. 定时干（五鼠遁）
- 核心规则：根据日干，通过五鼠遁口诀推算时干，以子时为基准，顺推其余时辰。
- 五鼠遁口诀：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸壬子起。
- 逻辑说明：日干为甲或己，子时时干为甲；日干为乙或庚，子时时干为丙，以此按六十甲子顺序顺推其余时辰的时干。

## 使用说明
1. 四柱排盘的核心前提是时间校准，必须先完成真太阳时换算与日界确定，再进行各柱的推算，否则排盘结果完全错误。
2. 年柱、月柱的分界必须严格遵循节气规则，年柱以立春为界、月柱以节为界，不可使用春节、农历初一作为分界标准，这是命理排盘的核心红线。
3. 日柱的确定必须严格遵循子时分界规则，23:00后出生必须按次日日柱计算，不可沿用当天日期的日柱。
4. 月干、时干的推算必须严格遵循五虎遁、五鼠遁口诀，基准点不可错位，顺推顺序不可颠倒。
5. 四柱排盘的结果必须结合出生地、出生时间的节气、时辰基准进行二次校验，确保每柱干支的准确性，这是后续命理分析的基础。

## 核心注意事项
1. 真太阳时换算不可省略，尤其是出生地与北京时间经度差异较大的地区，经度差修正直接影响时辰的判断，进而影响时柱的准确性。
2. 立春的具体时刻每年都不同，必须以当年精确的立春时分秒为分界点，不可笼统按2月4日一整天作为立春标准。
3. 五虎遁、五鼠遁的口诀基准点不可混淆，五虎遁以年干推月干、五鼠遁以日干推时干，二者适用场景完全不同。
4. 日柱的查表必须使用精准的百年对照表，不可使用错误的简化对照表，避免日柱干支查询错误。
