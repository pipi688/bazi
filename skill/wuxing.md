# 五行基础规则 Skill
## 描述
本Skill提供中国传统命理文化中「五行」的完整基础定义、属性分类、生克规则与流通关系，明确木、火、土、金、水五行的核心对应属性、相生相克底层逻辑，以及命理分析中五行流通的核心判断规则，可用于八字排盘、命理分析、易学研究等相关场景。

## 适用场景
1. 八字命理排盘与深度格局分析
2. 五行属性、生克关系与流通规则快速查询
3. 传统易学文化相关的教学、研究与资料整理
4. 命理类应用/工具的核心基础数据支撑
5. 八字五行强弱计算、十神配置与格局判断的基础规则参考

## 五行生克核心规则
### 相生规则（能量正向流通）
五行相生为有序的能量滋生关系，顺序固定：
1. 木生火
2. 火生土
3. 土生金
4. 金生水
5. 水生木

### 相克规则（能量制衡关系）
五行相克为有序的能量制衡关系，顺序固定：
1. 木克土
2. 火克金
3. 土克水
4. 金克木
5. 水克火

## 五行流通核心规则（泄生截盖）
| 流通类型 | 定义 | 核心影响 |
|----------|------|----------|
| 盖头 | 天干克地支 | 地支受伤，藏干无力，根基不稳 |
| 截脚 | 地支克天干 | 天干无力，外在表现打折 |
| 扎根 | 天干在地支有根 | 天干有根，内在有支撑 |
| 得生 | 地支生天干 | 天干得助，外在有助力 |
| 泄气/泄秀 | 天干生地支 | 能量流通，才华有出口 |

## 使用说明
1. 五行属性为命理分析的基础核心，十神、格局、强弱判断均需以五行的生克关系为底层逻辑
2. 相生关系代表能量的滋生、助力，为正向流通；相克关系代表能量的制衡、约束，为反向制衡
3. 五行流通规则是判断八字中天干与地支相互作用的核心标准，直接影响天干的发挥力度与地支的根基强度
4. 不同五行对应不同的人事、行业、方位、季节等属性，可用于命理中的事象推断与趋势分析
5. 天干与地支的阴阳属性必须严格匹配，阳干对应阳地支，阴干对应阴地支，是五行属性匹配的基础原则
